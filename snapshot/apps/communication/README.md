# Dizz Communication — Kommunikation

Die Kommunikations-Zentrale des Dizzi-Netzwerks: E-Mail (alle Anbieter), Messenger
(WhatsApp/Signal/Telegram/Instagram — Webview- + Matrix-Bridge-Schiene), Video-Calls.
Eigenständige, einzeln verkaufbare App; im Verbund per Dizzi-ID/SSO + MCP + Dashboard-Kachel.
