Kurz gesagt: Diese Website setzt keine Cookies, bindet nichts von fremden Servern ein und misst nichts. Was trotzdem anfällt, steht hier.

2. Was diese Website nicht tut

  • Keine Cookies – auch keine technisch notwendigen. Deshalb gibt es kein Einwilligungsbanner.
  • Keine Reichweitenmessung, keine Analyse-Werkzeuge, kein Tracking.
  • Keine externen Einbindungen: keine CDNs, keine Karten, keine Videos, keine sozialen Netzwerke, keine Schriftarten von fremden Servern. Die verwendeten Schriften (Orbitron, Chakra Petch) liegen auf demselben Server und werden nicht von Google geladen.
  • Kein Kontaktformular. Es gibt keine Eingabefelder, mit denen Sie mir Daten übermitteln könnten.
  • Kein JavaScript auf den Seiten dieser Website, mit zwei gekennzeichneten Ausnahmen. Die erste ist die interaktive System-Karte unter /karte/: Die Karte bringt eigenes, mitgeliefertes JavaScript mit und prüft beim Öffnen einmalig, ob auf Ihrem eigenen Rechner unter 127.0.0.1:8200 ein Dizzi-Core läuft; antwortet dort nichts, zeigt sie die Offline-Ansicht. Diese Anfrage verlässt Ihr Gerät nicht: sie geht ausschließlich an Ihren eigenen Rechner, und es wird kein fremder Server kontaktiert. Dieser Hinweis steht hier, weil diese Anfrage der einzige Netzwerkvorgang ist, den diese Website von sich aus auslöst – vom Abruf der Seiten selbst abgesehen (dazu Abschnitt 3). Die zweite ist das Spiel DizzCube unter /dizzcube/play/: Es bringt eigenes, mitgeliefertes JavaScript mit, stellt nach dem Laden keine Verbindung her und speichert nichts auf Ihrem Gerät; Punktestände und ein eingegebener Spielername bestehen nur, solange die Seite geöffnet ist, und verlassen Ihr Gerät nicht.
